## Project Description
VisitRwanda is a database-driven system designed to manage tourism information, destinations, visitor statistics and booking records.

## Objectives
1. Manage visitor information.
2. Organize tourism destinations.
3. Record accommodation and booking information.
4. Manage booking and payment records.
5. Generate tourism statistics and reports.

## Planned Database Tables
- VISITOR
- DESTINATION
- ACCOMMODATION
- BOOKING
- BOOKING_DETAILS
- PAYMENT
- TOURISM_STATISTICS
- COUNTRY
