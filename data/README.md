
# VisitRwanda – Data

## Purpose
This folder stores the datasets used in the VisitRwanda project.

## Planned Data
- Visitor records
- Tourism destination records
- Accommodation records
- Booking records
- Payment records
- Tourism statistics
- Country information

## Data Collection
Tourism statistics will be obtained from verified official sources. Sample booking records will be prepared and clearly identified for educational purposes.

## Data Preparation
The collected data will be organized, checked and prepared for use in the Oracle database.

## Privacy
No unnecessary personal or confidential visitor information will be included.
