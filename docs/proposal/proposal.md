
# VisitRwanda
## Tourism Statistics and Booking Records Management System

### 1. Problem Statement
Tourism information and booking records need to be properly organized to support effective tourism management. Without a centralized system, it can be difficult to monitor visitors, destinations, bookings and tourism statistics.

### 2. Proposed Solution
VisitRwanda will be an Oracle database system designed to manage visitor information, tourism destinations, accommodation, bookings and payments.

### 3. Data Sources
The project will use tourism statistics from the National Institute of Statistics of Rwanda and Rwanda Development Board. Sample booking records will be created and clearly documented for educational purposes.

### 4. Planned Tables
- VISITOR
- DESTINATION
- ACCOMMODATION
- BOOKING
- BOOKING_DETAILS
- PAYMENT
- TOURISM_STATISTICS
- COUNTRY

### 5. Planned PL/SQL Features
- Procedures for registering visitors and creating bookings.
- Functions for calculating booking costs.
- Cursors for generating tourism reports.
- Triggers for updating booking information.
- Packages for organizing booking operations.
- Reports for analyzing tourism statistics.

### 6. Innovation
An Oracle APEX application with a tourism analytics dashboard and automated booking management.

### 7. References
Verified tourism statistics, research papers and Oracle technical documentation will be included.
